PORTOFOLIO RIFA — FILE WEBSITE

Struktur:
- index.html  : struktur dan konten website
- style.css   : seluruh tampilan, warna, dan responsive layout
- script.js   : interaksi navigasi dan tahun otomatis

Cara menjalankan:
1. Ekstrak folder/ZIP.
2. Pastikan ketiga file berada dalam folder yang sama.
3. Buka index.html menggunakan browser.

Bagian yang perlu kamu personalisasi:
- Ganti link Instagram, LinkedIn, dan GitHub di index.html.
- Ganti hello@example.com dengan alamat email kamu.
- Perbarui pengalaman dan project contoh dengan informasi asli.
- Ilustrasi monogram R pada hero saat ini adalah placeholder desain; bisa diganti foto atau karya milikmu.
